  > Lets the agent drive a real browser through Tencent BrowserSkill. Install first, both at version 0.3.3: the bsk command-line tool on PATH and the BrowserSkill extension connected in Chrome or Edge (github.com/Tencent/BrowserSkill, Quick start); if VibeDev then reports that it cannot find bsk, restart VibeDev or set the plugin's bskPath to the full path. It drives your signed-in browser, so the agent can act on sites where you are logged in: use a separate browser profile for it and keep the extension's confirmation settings on. The plugin launches bsk processes, and the browser visits the sites the agent chooses. Session recovery records are kept in ~/.bsk. The bsk background service updates itself every 30 minutes by default; set the environment variable BSK_AUTO_UPDATE=off to keep it at the version that matches this plugin.
